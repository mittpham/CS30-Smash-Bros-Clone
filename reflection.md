# Capstone Project CS30 - Reflection

## What advice would you give to yourself if you were to start a project like this again?
- I would have told myself to create a better base game that supported future additions. The way that I made the minimum viable product worked, but made it very tedious and time consuming to add more to it later on. Instead, I should have made a skeleton structure that would easily support new mechanics, whether I actually implement them or not.
